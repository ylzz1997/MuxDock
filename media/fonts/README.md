# Powerline symbols

`PowerlineSymbols.otf` is the unmodified symbol font from
[powerline/powerline](https://github.com/powerline/powerline/blob/11808cbe5c16e4621edcaefa916b5add81eab799/font/PowerlineSymbols.otf),
commit `11808cbe5c16e4621edcaefa916b5add81eab799`.

It is distributed under the MIT license in `LICENSE-Powerline.txt`. The build
bundles the font and its license into `dist/`, including in packaged extensions.
The CSS face exposes only U+E0A0–U+E0A2 and U+E0B0–U+E0B3; normal text and the
font's full-block glyph continue to use the user's terminal font.
