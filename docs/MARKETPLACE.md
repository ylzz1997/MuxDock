## Short description

## Overview

Persistent terminal sessions. One dock.

MuxDock puts your terminal on the left and your managers and named sessions on the right. Attach to existing sessions, create new ones, switch between terminal tabs and browse tmux windows without leaving your editor.

Keep the native behavior of your tools: keyboard shortcuts, pane layouts, status bars, shell prompts and colors. Closing a tab detaches its client while the session continues in the background.

Choose which managers appear, reveal the session filter only when needed and set a maximum number of tabs. Collapse the session panel to give the terminal more space, then restore it with the same toolbar button. Use MuxDock on a local macOS/Linux workspace or on a remote Linux workspace through SSH, WSL or Dev Containers.
